# oxzoo-vue-django

Official [ox](https://github.com/saurav-codes/vps-ctl) deploy example: a Django 5.2 LTS JSON-free text API and a Vue 3 single-page app on one Ubuntu VPS, where nginx serves the built SPA statically and proxies `/api` and `/health` to gunicorn. The backend greets you with a tag from runtime env, the frontend bakes the same tag in at build time, so one variable demonstrates both environment flows.

## Stack

| Layer | Tool | Pin |
|---|---|---|
| Backend | Django | 5.2 LTS (exact pin in `pyproject.toml`) |
| App server | gunicorn | 23.x (exact pin) |
| Python manager | uv | `pyproject.toml` + `uv.lock` + `.python-version` (3.13) |
| Frontend | Vue 3 + Vite 5 | npm, exact pins in `package.json` |
| Web | nginx | serves `dist/`, proxies `/api` + `/health` |
| Deploy | ox | systemd + nginx from `ox.toml` |

## Environment flow

| Variable | When it is read | Where it is set |
|---|---|---|
| `GREETING_TAG` (backend) | at RUNTIME, `os.environ.get("GREETING_TAG")` per request | ox Environment editor (`/etc/ox/apps/oxzoo-vue-django.env`) |
| `GREETING_TAG` (frontend) | at BUILD time, baked into the bundle via `envPrefix = ["GREETING_", "VITE_"]` | ox Environment editor, present when the `npm run build` hook runs |
| `DJANGO_SECRET_KEY` (backend) | at RUNTIME | ox Environment editor (example ships a placeholder default) |

nginx (generated by ox) serves `dist/` with `try_files ... /index.html` (SPA mode) and keeps only the `[frontend].api_paths` prefixes, `/api` and `/health`, proxied to gunicorn on `127.0.0.1:9108`.

## Deploy with ox

1. Paste the clone URL into the ox dashboard: `https://github.com/saurav-codes/oxzoo-vue-django.git`
2. Open the Environment editor and set `GREETING_TAG` BEFORE the first deploy (e.g. `GREETING_TAG=w2-07`). The build hook bakes it into the frontend, so it must exist before the first deploy. Optionally set `DJANGO_SECRET_KEY` there too.
3. Press Deploy. ox installs Python deps with `uv sync --frozen` and frontend deps with `npm install` (repo-local, no global installs), builds `dist/`, then starts gunicorn.

Django needs no migrate hook in this example: there are no models, `DATABASES = {}` is empty, and a sqlite file would be unwritable at runtime under the sandbox.

## Expected output

With `GREETING_TAG=<your-tag>`, the page shows:

```
frontend: hello world oxzoo-vue-django_<your-tag>
backend: hello world oxzoo-vue-django_<your-tag>
```

`GET /health` returns `200 ok` and is used as the deploy readiness check.
